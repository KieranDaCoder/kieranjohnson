# Archive

Projects moved here are NOT shown on the site (the loader only reads
`content/projects/`) and are ignored by `npm run check:content`.

To bring one back: move its file from `content/archive/projects/` to
`content/projects/` (check its `order:` and that its image paths still exist).
Their placeholder images are still in `public/placeholders/`.
